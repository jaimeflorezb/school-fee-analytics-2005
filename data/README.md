# Data

This directory contains the data required to reproduce the main analytical
results of the 2005 study.

## Data sources

The original project was based on household and student socioeconomic
information collected for the Colegio Luis Horacio Gómez in Cali, Colombia.

The original administrative files contain detailed household and student
information and are therefore not distributed directly in this public
repository.

## Public replication data

The repository will provide analytical datasets derived from the original
records and designed to reproduce the published results.

The replication files will include:

- `model_data_2005.csv`  
  Data required to reproduce the original econometric models.

- `descriptive_data_2005.csv`  
  Data required to reproduce the main socioeconomic descriptive results.

- `tariff_scenarios_2005.csv`  
  Data required to reproduce the alternative school-fee scenarios and
  financial calculations.

- `data_dictionary.csv`  
  Variable definitions, units, coding, and methodological notes.

## Original microdata

The surviving original databases contain household-level socioeconomic
information.

These files are preserved separately and are not currently distributed through
the public repository because some records contain identifying or potentially
identifiable information.

The public replication datasets preserve the analytical information required
for reproducibility while excluding direct personal identifiers.

## Reproducibility

The objective is to allow users to:

1. Download the replication data.
2. Re-estimate the original econometric models.
3. Reproduce the descriptive statistics.
4. Reconstruct the tariff scenarios.
5. Compare the original 2005 methodology with modern re-estimations.

## Data integrity

Replication datasets are derived from the surviving original files.

Any differences identified between archival versions of the databases are
documented before constructing the public replication files.
