# Replication Data

This directory contains public replication data reconstructed from the surviving
files of the original 2005 project.

## Files

- `descriptive_data_2005.csv`  
  Original grouped socioeconomic descriptive distributions.

- `tariff_scenarios_2005.csv`  
  Original tariff scenarios and financial calculations organized in reusable
  long format.

- `archival_model_results_2005.csv`  
  Econometric results reported in the original study.

- `data_dictionary.csv`  
  Variable definitions, units, and source information.

## Econometric replication

The original study reports six observations for the selected econometric model.

The exact six-row analytical design matrix is currently being reconstructed
from the surviving archival databases and will only be added after the original
coefficients and diagnostics have been independently reproduced.

No synthetic or guessed observations are used in this repository.
