# School Fee Analytics 2005

This repository reconstructs an undergraduate Economics project developed at
Universidad Autónoma de Occidente, Cali - Colombia, in 2005.

## Project overview

The original study developed a methodology for determining school tuition and
fees based on household socioeconomic characteristics, ability to pay,
willingness to pay, equity considerations, and the financial sustainability
of the educational institution.

From a contemporary data analytics perspective, the project combines:

- Descriptive analytics
- Econometric modeling
- Predictive analysis
- Household segmentation
- Scenario analysis
- Prescriptive decision-making
- Financial analysis

## Original study

**Title:** Metodología para la determinación de tarifas con base a los
indicadores socioeconómicos de la familia: el caso del Colegio Luis Horacio Gómez

**Authors:**
- Jaime Flórez Bolaños
- Lear Yadim Murillo Henao

**Institution:** Universidad Autónoma de Occidente  
**Program:** Economics  
**Year:** 2005

## Repository objective

The purpose of this repository is to preserve, document, and reproduce the
original analysis while also developing a modern re-estimation using
reproducible data-analysis tools.

The repository distinguishes between the original 2005 methodology and later
extensions using contemporary econometric and data analytics techniques.

## Data privacy

The original study used household-level socioeconomic information.

Raw microdata are not publicly distributed in this repository because some
files contain confidential or potentially identifiable information.

Publicly available materials will therefore focus on:

- Documentation
- Reproducible code
- Aggregated results
- Model outputs
- Anonymized or synthetic data when appropriate
